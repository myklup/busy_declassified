# Busy, Declassified

Chrome extension that replaces Google Calendar "busy" chips with humorous alibis in your browser only.

## Privacy policy

- Markdown: [PRIVACY.md](PRIVACY.md)
- HTML (use this URL in the Chrome Web Store after GitHub Pages is on): [privacy.html](privacy.html)

To get a stable HTTPS page for the Chrome Web Store Privacy policy field:

1. Repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / `/ (root)`
4. Save, then use:

```
https://myklup.github.io/busy_declassified/privacy.html
```
